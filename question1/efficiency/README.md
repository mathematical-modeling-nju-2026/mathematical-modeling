# 问题1：题目「充放电效率 90%」两种口径的结果对照

## 1. 歧义来源

题干（附录 1）只写「充放电效率为 90%」，未指明是**哪一侧**的效率。
两种主流理解如下，且会给出**不同的最优调度与不同的费用**：

| | 定义一（题目主口径：充、放效率各90%） | 定义二（将90%解释为往返效率的敏感性口径） |
|---|---|---|
| 表述 | 充电效率 90%、放电效率 90% | **放电量 / 充电量 = 90%** |
| 数学式 | $E_t=E_{t-1}+0.9c_t-d_t/0.9$ | $E_t=E_{t-1}+\eta c_t-d_t/\eta,\ \eta=\sqrt{0.9}$ |
| 参数 | $\eta_c=\eta_d=0.900000$ | $\eta_c=\eta_d=0.948683$ |
| **往返效率** | $0.9\times0.9=\mathbf{0.81}$ | $\eta_c\eta_d=\mathbf{0.90}$ |
| 物理含义 | 充入 1 kWh 电池内只增 0.9；取出 1 kWh 外部只得 0.9 | 充入 1 kWh 最终只能放出 0.9 kWh |

> 本目录采用**对称拆分** $\eta_c=\eta_d=\sqrt{0.9}$，使两侧损耗相同且往返恰为 0.90。
> 另有「仅充电侧损耗」($\eta_c=0.9,\eta_d=1$) 与「仅放电侧损耗」($\eta_c=1,\eta_d=0.9$)
> 两种拆法，往返同为 0.9，但会使充/放电量统计口径不对称，故未采用。

### 4.2 收益来源分解（严格恒等式，可复现）

分解式：$\underbrace{\sum p_t\max(L_t\!-\!V_t,0)-\sum p_tg_t}_{\text{总节省}}
=\underbrace{\sum p_t\max(V_t\!-\!L_t,0)}_{\text{弃光消除}}
+\underbrace{\sum p_td_t-\sum p_tc_t}_{\text{净套利}}$

| 项目 | 定义一（元） | 定义二（元） | 差异 |
|---|---:|---:|---:|
| ① 光伏余电消纳 | 4,037.75 | 4,037.75 | **0** |
| ② 峰谷价差套利 | 8,887.35 | 10,212.81 | **+1,325.45** |
| **合计节省** | 12,925.10 | 14,250.55 | +1,325.45 |

**结论**：两个口径下光伏余电消纳完全相同（基线一致、余电量一致），
费用差异**全部来自套利项**——往返效率由 0.81 提到 0.90 后，
「低价充、高价放」的损耗变小，套利空间随之扩大。

### 4.4 调度结构差异

144 个时段中有 **112 个时段**充放电量不同（其余因约束边界恰好相同）。
差异集中在：

- **01:30、23:20**：定义二各少充 273.69 kWh（凌晨充电量下调）
- **05:50、18:10**：定义二各多放 591.14 / 467.36 kWh（高价时段放电增强）
- **11:10、11:40、15:10**：定义二少充 11–179 kWh（中午补电减少）

总体规律：**损耗更小 → 夜间少充、高价时段多放、中午补电减少**，
即电池的「搬运效率」提高后，调度更依赖跨时段搬移而非提前大量储电。

## 5. 结论与建议

1. 题面明确“充、放电效率均为90%”，因此定义一是主口径；定义二仅作为往返效率解释下的敏感性分析。两者费用相差 1,325.45 元（3.77%），
   题目指定表格中的 **18:00–18:10 购电量**差异尤其显著（531.89 → 64.53 kWh），
   因此**必须在论文中明确声明采用的是哪一种**，并建议两者都给出。
2. 本仓库原有结果（`question1/results/`）对应**定义一**（往返 0.81）。
3. 若将90%解释为往返效率（定义二），全天购电费为 **33,801.50 元**、节省 **29.66%**；该结果仅作敏感性分析。
4. 建议论文的建模假设中补一句说明，例如：
   > 本文主口径取充、放电单向效率各 90%
   > （往返 0.81）；另将「90%」解释为往返效率（对称拆分
   > $\eta=\sqrt{0.9}$），全天购电费为 33,801.50 元、节省 29.66%，
   > 见 `question1/efficiency/def2_roundtrip90/`。

## 6. 校验

两种口径下均通过全部检查项：

- 同一时段不同时充放电（违反时段数 = 0）
- 储电量 ∈ [1200, 10800] kWh
- 0:00 与 24:00 储电量相同（6000 kWh）
- 逐段能量平衡（最大残差 ~1e-13）
- 充/放电量 ≤ 833.33 kWh/段
- 电量递推式自洽（最大偏差 ~1e-12）
- 弃光量非负（模型约束，弃光合计 0）
- 弃光量未超光伏出力（本实例数值观察，**非**模型约束）
- 购电量非负
- 收益分解恒等式残差 ~1e-12

> 模型不设弃光上界 $w_t\le V_t$（证明见 [../建模说明.md](../建模说明.md)）：
> 平衡为等式且目标只惩罚购电，最优解自动满足该式，显式上界冗余。
> 因此“未超光伏出力”只是本实例 $w_t\equiv0$ 下的观察，不作为可行性判据。
