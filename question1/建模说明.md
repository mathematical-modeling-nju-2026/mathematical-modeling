# 第一问：典型日确定性储能调度

## 目标、输入与假设

采用用户指定的 `C_yang/q1`，最小化典型日外网购电费用。输入为 [附件1](../data/附件/附件1.xlsx)，一天144个10分钟时段；表中负载、光伏功率乘以 $\Delta t=1/6$ 小时转为电量。数据标签为区间末时刻。

假设典型日负载、光伏和电价已知；不向外网售电，光伏可弃置；不加入未在原代码出现的折旧费用。单向充放电效率均为0.9，容量边界1200—10800 kWh，充放电功率上限5000 kW，日初与日末均为6000 kWh。

## 变量、模型与求解

| 符号 | 含义及单位 |
|---|---|
| $p_t$ | 电价，元/kWh |
| $L_t,V_t$ | 负载、光伏电量，kWh/段 |
| $g_t,c_t,d_t,w_t$ | 外网购电、充电、放电、弃光量，kWh/段 |
| $E_t$ | 时段末内部储电量，kWh |

$$\min\sum_{t=1}^{144}p_tg_t$$
$$g_t+V_t+d_t=L_t+c_t+w_t,\quad 0\le w_t\le V_t,\quad g_t\ge0,$$
$$E_t=E_{t-1}+0.9c_t-d_t/0.9,\quad 1200\le E_t\le10800,$$
$$0\le c_t,d_t\le5000/6,\quad E_0=E_{144}=6000.$$

构建稀疏LP并用SciPy/HiGHS求解；另解加入充放电互斥二元变量的MILP进行对照。随后检查能量平衡、SOC递推、上下界和互斥，计算无储能基线与对偶边际电价，再导出表格。LP与MILP一致是本实例已有计算结果；本次整理不重新优化。

## 文件及运行

| 文件 | 职责 |

在仓库根目录安装 `requirements.txt` 后运行：

```powershell
python -X utf8 question1/code/run_q1.py
python -X utf8 question1/code/plot_q1.py
```

脚本内部路径均相对于文件位置；从其他工作目录可用脚本绝对路径启动。输出写入 `results/`，图片在 `results/figs/`。运行主程序会更新同名结果，论文使用的现有结果应先备份。
