本目录存放 **问题二（微网购电策略）** 的独立方案，供团队评审与合并参考。

|---|---|

## 方法一句话概括

**24h 随机规划 + 终端储能价值**：每天 0:00 用严格历史数据做负载/光伏预测，叠加最近 28 天整日联合残差构造场景，解含"终端储能价值 λ·E_end"的单阶段随机 LP；当天执行时储能按计划、缺口紧急购电、盈余弃电；储能跨日滚动。
