# 方案 C —— 问题三：多时点光伏预报下的调整购电策略

> **全年总费用 1432.49 万元**（2025-02-01 ~ 12-31，334 天）
> 相比"不调整"（1466.29 万元）**节省 33.80 万元**。

## 一、一句话概括

在"每天 0:00 制定计划、6:00/12:00/18:00 依新预报调整"的框架下，
建立 **日前两阶段随机规划 + 多时点滚动调整** 模型，
并用 **附件 3 光伏预报（整点线性插值对齐）** 驱动调整，
在满足储能全部物理约束的前提下最小化"计划费 + 调整费 + 紧急购电费"。

## 二、结果速览

| 方案 | 计划费(万) | 调整费(万) | 紧急费(万) | 合计(万) |
|---|---|---|---|---|
| 不调整（仅 0:00 计划）| 1374.61 | 0.00 | 91.68 | 1466.29 |
| **调整（6/12/18）** | **1374.61** | **−8.98** | **66.87** | **1432.49** |
| 完美预见（理论下界）| 1374.61 | −61.71 | 10.13 | 1323.03 |

**调整收益来源**：紧急购电费从 91.68 万降至 66.87 万（−24.81 万）

- 调减计划量获得"违约费节约" 8.98 万（负的调整费）
- 减少紧急购电 24.81 万

## 三、"是否引入其他时刻预报"的结论

| 单时点 | 节省(万) | | 组合 | 节省(万) |
|---|---|---|---|---|
| 仅 6:00 | 19.57 | | **6+12** | **33.88** |
| **仅 12:00** | **22.41** | | 12+18 | 22.33 |
| 仅 18:00 | −0.06 | | 6+12+18 | 33.80 |

**结论**：12:00 单点贡献最大；**6:00+12:00 已达饱和**（33.88 万，占可实现收益 94%）；
18:00 单独启用几乎无收益。**无需引入 18:00 之后的时点**；若可新增，
应置于白天光伏爬坡前（8:00~10:00）与午后电价转高前。

**更强的证据**（预报源敏感性，见说明文档 6.3）：
把附件 3 与统计预测融合（α=0.3），光伏预报 MAE 从 225.8→142.8 kW，
全年费用再降 112.6 万 —— **预报精度远比时点数量重要**。

## 四、关键建模要点

### 4.1 费用函数（本题最易错处）

$$C_t = p_t g_t^{p} + 1.5\,p_t u_t - 0.5\,p_t v_t + 5\,p_t e_t$$

其中 $u_t=\max(0,g^{a}-g^{p})$（调增）、$v_t=\max(0,g^{p}-g^{a})$（调减）。

**$v_t$ 的系数必须是 $-0.5p$**（调减部分按 50% 计费 → 净省 0.5p）。
反证：若取 $+0.5p$，则任何调减都增加成本 → 最优解永不调整 → 题目失去意义。

### 4.2 附件 3 时间对齐（隐形 bug 高发区）

- "预报 $k$ 小时" = 发布时刻 + $k$ **整点**的**瞬时**功率（非小时均值）；
- 以 24 个整点为锚点在 10 分钟网格**线性插值**（MAE 132~236 kW，
  远优于分段常数的 307~431 kW）；
- ⚠️ 对齐错误曾导致"调整反而更贵 284 万"，是隐蔽性极强的实现陷阱。

### 4.3 计划模型（沿用问题二方案 B）

- **48h 前瞻**两阶段随机规划；
- **计划供给下界用不等式**（$g^p+d-c \ge \hat N$）+ **场景平衡**（$+e_s \ge N_s$）；
- 周期终端 $E_{24}=E_0$，年末回 6000 kWh。
