## 阶段一：修复无法跑通的问题

### 问题 1（致命）：附录 B 缺步骤，Q2 流程在第 2 步即中断

附录 B 原文只写两步：

```
python Q2/code/run_experiment.py --first-residual 7 --only uniform56 --out recommended_only
python Q2/code/make_target_tables.py
```

实测报错：

```
FileNotFoundError: '...\Q2\results\schedule_detail.csv.gz'
```

原因：`--out recommended_only` 把结果写入 `Q2/results/recommended_only/`，
而 `make_target_tables.py` 读 `Q2/results/schedule_detail.csv.gz`。
**漏掉了 `report_experiment.py`** —— 它的职责正是把推荐方案从子目录提升到
`Q2/results/` 根（`shutil.copy2`）。且完整流程需要 3 个实验口径分组，
附录只写了 1 个。

### 问题 2：`verify_window.py` 表头断言与结果文件不符（Q2 核验必然 FAIL）

```
errors: ['plan_interval_headers', 'plan_slot_energy_max_error']
plan_slot_energy_max_error = 1455.73
```

`verify_window.py` 第 304 行硬编码期望表头 `0:00-0:10, 0:10-0:20, ...`，
但 `result2.xlsx` 用的是**附件5 模板的环形表头**：

| | 第 1 格 | 最后 1 格 |
|---|---|---|
| 实际 | `0:10-0:20` | `0:00-0:10+1` |
| 期望 | `0:00-0:10` | `23:50-24:00` |

表头不匹配 → 整列**错位**比较 → 单格误差高达 1455.73 kWh。
（与 2026-09 修复的 Q3 `verify_q3.py` 属同一类缺陷，当时 Q2 漏修。）

**附加发现**：官方模板个别标签分钟位不足两位，如 `7:0-7:10`（应为 `7:00-7:10`），
解析时须按整数读取分，不能用 `\d{2}` 强约束。

### 问题 3：支撑材料缺 `common/q2_base/summary.json`

`report_experiment.py` 第 40 行读 `SOURCE.parent/'summary.json'`，
用于校验"原目录基线已精确复现"（`old_gap <= 1e-6`），但该文件未收录。

### 问题 4：`Q4/part3/code/run_q3.py` 缺 `import sys`

第 21 行使用 `sys.path` 但未导入：

```
NameError: name 'sys' is not defined. Did you forget to import 'sys'?
```

（与 2026-09 修复的 Q3 `run_q3.py` 属同一 bug，Q4-3 这份漏修。）

### 问题 5（非缺陷）：`--out` 会破坏后续核验

`run_q3.py` / `run_q42.py` 的 `--out` 默认值为 `HERE`（本问 `results/` 根），
正确用法是**不传** `--out`。附录 B 原文传了 `--out reproduced` / `--out out`，
导致结果写入子目录、核验脚本找不到。

## 阶段二：修复 xlsx 表头规则不统一

### 问题 6：19 个变体/对照 xlsx 仍用旧「位置保持」规则

统计全部 `result*.xlsx` 时发现两套规则并存：

| 规则 | 数量 | 内容 |
|---|---|---|
| 环形（模板）✓ | 12 | 5 个附件5模板 + 6 个交付表 + `Q2/result2.xlsx` |
| 位置保持 ✗ | 19 | 全部变体/对照目录 |

**题目要求的 5 个交付表全部是环形规则，正确无误。**问题只在 19 个变体/对照。

成因：提交 `47fe830`「恢复附件5原表头并按环形映射填数」给 `export_workbook`
与 `export_excel` 加了环形映射，但**只重建了各问主目录的 xlsx，未重跑变体子目录**。

**验证**：代码本身已正确 —— 重跑生成命令后，变体 xlsx 表头即为
`0:10-0:20`（环形）。19 个旧文件纯粹是"没重跑"的历史遗留。

修复：按附录 B 完整流程重跑（变体 xlsx 由 `run_experiment.py` /
`run_q42.py` 自动重生成），另对两个 `at_0_6_12` 对照目录执行
`--mode at_0_6_12` 显式生成。

### 问题 7：Q4-2 元数据指向已删除的 `question2/` 目录

```
run_metadata.json:                  "q2_source": "question2\\results"
source_fingerprints.migrated.json:  "question2\\code\\rolling_window.py": ...
```

`run_q42.py` 写的是 `q2_source=str(BASE_DIR.relative_to(REPO))`，而 `BASE_DIR`
已改指 `Q2/results`。重跑后自动修正为 `Q2\results`，指纹也不再含 `question2`。

### 问题 8：Q4-3 存在冗余文件与复制自 Q3 的说明文字

- `Q4/part3/results/result3.xlsx`（1,042 KB）——Q4-3 只应产出 `result4-3.xlsx`，多余
- `Q4/part3/results/comparisons/at_0_6_12/result3.xlsx`——同上
- `Q4/part3/results/run.err`、`run.log`——运行日志，非交付内容
- `run_q3.py` 生成的结果说明文字写作 `result3.xlsx`，应为 `result4-3.xlsx`

处理：删除前 4 项；修正说明文字。
