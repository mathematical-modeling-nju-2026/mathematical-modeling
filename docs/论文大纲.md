## 三、问题一：典型日确定性储能调度（约 2 页）

### 3.1 模型建立
变量表（$p_t, L_t, V_t, g_t, c_t, d_t, w_t, E_t$）；目标与约束：

$$\min\sum_{t=1}^{144}p_tg_t$$
$$g_t+V_t+d_t=L_t+c_t+w_t,\qquad 0\le w_t\le V_t$$
$$E_t=E_{t-1}+0.9c_t-\frac{d_t}{0.9},\qquad 1200\le E_t\le10800$$
$$0\le c_t,d_t\le \tfrac{5000}{6},\qquad E_0=E_{144}=6000$$

**共 720 个变量**（g/c/d/E/w 各 144），稀疏 LP，HiGHS 求解。

### 3.2 关键理论：为何 LP 松弛是紧的（论文亮点）
设某段同时充放电，取 $\varepsilon=\min\{c_t,0.81d_t,g_t/0.19\}$，令 $c_t\!\leftarrow\!c_t-\varepsilon,\ d_t\!\leftarrow\!d_t-0.81\varepsilon$，则
$$0.9(c_t-\varepsilon)-\frac{d_t-0.81\varepsilon}{0.9}=0.9c_t-\frac{d_t}{0.9}$$
**SOC 轨迹完全不变**，而能量平衡给出 $g_t\leftarrow g_t-0.19\varepsilon$ —— 购电严格下降。
故只要该段仍在购电，拆开必然更省 → 最优解中 $c_td_t=0$ 自动成立，**无需二元变量**。
本实例 LP 与 MILP 目标值**完全相同**（35,126.95 元，差 0.000000）。

电量平衡：购电 59,482.70 / 光伏 55,482.84 / 放电 16,799.94 kWh；负载 111,024.81；弃光 **0**

## 四、问题二：滚动随机日前调度（约 3 页）

### 4.1 问题本质：报童型结构
题面"其他时间段的购电费用均按计划购电量计算"→ 计划量照付（$c_o=p$），仅缺额加价（$c_u=4p$）
$$\text{临界分位}\ F^*=\frac{c_u}{c_o+c_u}=\frac{4}{5}=0.80$$
→ 计划购电量应取净负载的 **80% 分位**，而非均值。这是全文的核心经济学洞察。

### 4.2 两阶段随机规划模型
$$\min\sum_{t\in48h}p_tg_t+5\sum_s w_s\sum_{t\in\text{当天}}p_te_{s,t}$$
$$g_t+d_t-c_t\ge\hat N_t,\qquad g_t+d_t-c_t+e_{s,t}\ge N_{s,t}$$
+ SOC 递推、边界、功率、$g_t\ge0$

**"不等式 + 场景兜底"** 的设计：计划下界用不等式（≥ 点预测），再以场景紧急购电 $e_{s,t}$ 兜底最坏情形。

### 4.3 预测方法（仅用历史，严格因果）
| 分量 | 方法 |
|---|---|
| 负载 | 最近 **4** 次同星期几均值 + 近 **5** 天残差漂移 |
| 光伏 | 近 **7** 天均值 + 近 **28** 天残差漂移 |

### 4.4 场景构造与"有效残差"修正
- 场景 = 点预测 + 历史**整日联合残差**（最近 **56** 天等权）
- **排除 1月1–7日回退残差**（`first_residual=7`）：负载内核在 1月1–7日无同星期历史，
  使用附件1典型日回退，其残差口径与后续不一致。这是本项目的主要优化点。

### 4.5 每日滚动执行
48h 前瞻窗口，只执行当天 144 段；**窗口末回到本次窗口起始 SOC**（不是每天日末回日初）

### 4.6 结果与对照
| 方案 | 总费用 | 说明 |
|---|---|---|
| 早期基线（滚动 q 分位） | 1700.6 万 | 起点 |
| 24h 确定性随机规划 | 1463.3 万 | — |
| **48h + 不等式 + 有效残差56天等权** | **1438.91 万** | **最终采用** |
| 半衰期 7/14/28 加权 | 均无稳定收益 | 见对照表 |
| 28/42 天短窗口 | 变差 | — |
| 在线选窗（4/6 候选） | 无稳定收益 | 严格无前视 |

**关键结论**：改进主要来自**排除回退残差**（省 1.29 万元），而非加权或选窗。

## 五、问题三：预报融合与场景树多时点调整（约 4 页）★ 核心

### 5.1 计费规则的统一建模（易错点，需重点阐述）
设 0 点原计划 $g_t^0$、最终 $q_t$，定义
$$u_t=(q_t-g_t^0)_+,\qquad v_t=(g_t^0-q_t)_+$$
$$J=\sum_t\big[p_tg_t^0+1.5p_tu_t-\underline{p_tv_t}+\underline{0.5p_tv_t}+5p_te_t\big]$$
即净调整费 $=1.5p_tu_t-0.5p_tv_t$，**可为负**。

**等价形式**（便于核验）：$J=\sum_t\big[p_t\min(g_t^0,q_t)+0.5p_tv_t+1.5p_tu_t+5p_te_t\big]$

**经济解释**：调减 1 kWh 少付 $p$、付违约费 $0.5p$ → 净省 $0.5p$。
**反证**：若把 $v$ 的系数写成 $+0.5p$，则任何调减都增加成本 → 最优解永不调整 → 题目失去意义。

### 5.2 在线预报融合（信息源整合）
附件3 的发布预报 $F$ 与历史预测 $H$ 按权重融合：
$$\alpha=\operatorname{clip}_{[0,1]}\frac{\sum(F-H)(V-H)}{\sum(F-H)^2},\qquad \text{融合}=\alpha F+(1-\alpha)H$$
+ 收缩偏差校正（系数 $n/(n+14)$），裁剪非负。

**训练约束**（严格非前视）：只用最近 56 天内**已完全验证**的预报行；只用不晚于 $d-2$ 天的样本（保证跨午夜的 24h 已实现）；样本 < 7 条时退化为纯发布预报；每个发布时刻**分别**训练。

### 5.3 时间对齐（实现关键）
附件3 "预报 $k$ 小时" = 发布时刻 + $k$ **整点**的**瞬时**功率。
→ 以 24 个整点为锚点、在 10 分钟网格上**线性插值**；发布瞬间端点用**已观测**的实际光伏。

### 5.4 经验场景树（多阶段信息分支）
场景净负载：$N_{s,t}=\hat N_t^{(a)}+\big(N_{r_s,t}-\hat N_{r_s,t}^{(a)}\big)$
- 取最近 56 个完整历史日；最早残差日 1月8日（2月1日 24 条，渐增至 56 条）
- 把历史日在**后续发布时刻的预报修订**作为未来信息，**二叉聚类**成树
- 每次只能按**届时新发布**的修订划分父节点 → 保证非前视
- 节点概率 = 落入该节点的历史日数 / 总数
- **每个节点只有一组共享的 $q,c,d,E$ 变量**，同节点内仅 $e_{s,t}$ 不同 → 变量结构上保证非前视
- 最多 4 层、15 个决策节点；56 条残差样本仍全部参与期望缺口成本

### 5.5 场景树 LP
$$\min\ \sum_tp_tg_t^0+\sum_n\pi_n\sum_{t\in n}(1.5p_tu_{n,t}-0.5p_tv_{n,t})+\frac1S\sum_s\sum_t5p_te_{s,t}+\text{次日前瞻}$$
$$q_{n,t}=g_t^0+u_{n,t}-v_{n,t};\qquad q,c,d,E\ge0,\ 1200\le E\le10800,\ c,d\le5000/6$$
子节点起点 SOC = 父节点终点 SOC

### 5.6 跨日价值与贪心执行
- 每次优化至**次日 24 点**，次日作确定性价值近似
- 前瞻终点回到**本日 0 点 SOC**（6/12/18 点重算时目标不变）
- 执行：0 点执行 0–6 时，6 点执行 6–12 时，12 点执行 12–18 时，18 点执行 18–24 时
- **为何不把 80% 分位硬编码**：场景树让 0 点能评估未来调整机会，故分位数随节点变化；
  80% 只是"固定储能 + 单期补救 5 倍"条件下的特例

### 6.2 4-2：波动电价下的日前调度

**(a) 电价信息假设（本题关键判断）**
题面未明确 0 点是否已知全天电价 → 保留两种：
- **主模型（当天电价未知）**：只用此前日期的电价预测，事后按附件4实际价结算
- 对照（当日电价已知）：明确放宽信息限制

**(b) 电价预测**：用 **1月8–31日**比较 4 种规则（前一日曲线 / 近7日均值 / 近7日形状+前一日水平 / 最近4次同星期几均值），以 1月预测 RMSE 选定，**2 月起固定**。
→ 入选：**最近 4 次同星期几均值**

**(c) 电价—净负载联合场景**（核心创新）
场景取自**同一历史日**的电价残差与净负载残差：
$$N_{s,t}=\hat N_{d,t}+r^N_{s,t},\qquad p_{s,t}=\max\{0.001,\ \hat p_{d,t}+r^p_{s,t}\}$$
**动机**：电价随机时 $\mathbb E[p_t(N_t-z_t)_+]\ne\mathbb E[p_t]\,\mathbb E[(N_t-z_t)_+]$ ——
**高电价可能与缺电同时发生**，不能分解。联合场景保留乘积期望。

**对照**：平均电价模型（保留相同净负载场景，电价取均值）检验配对关系的实际作用

**(d) 目标函数**
$$\min\sum_{t=1}^{144}\overline p_{d,t}g_t+5\sum_s\omega_s\sum_{t=1}^{144}p_{s,t}u_{s,t}+\sum_{t=1}^{144}\hat p_{d+1|d,t}g_{144+t}$$

**(e) 结果**
| 方案 | 总费用（元） | 相对 Q2 重结算 |
|---|---|---|
| 原 Q2 计划按附件4重结算 | 15,184,704.23 | — |
| 平均电价模型 | 15,160,921.45 | −23,782.79 |
| **联合场景模型（主）** | **15,163,043.89** | **−21,660.34（0.14%）** |
| 当日电价已知（对照） | 15,033,043.18 | −151,661.05 |

**诚实说明**：同年回测中均价近似略优于联合场景（差约 2000 元），但联合场景保留了正确的概率结构，
本文采用它作为主模型，并如实报告该现象。

|---|---|---|---|
| ① 在线预报融合 | 20.84 万 | 22.19 万 | 1.07 |
| ② 多时点调整 | **15.90 万** | **23.34 万** | **1.47** |
| — 加 6 点 | 8.01 万 | 12.20 万 | 1.52 |
| — 加 12 点 | 7.90 万 | 10.45 万 | 1.32 |
| — 加 18 点 | −38.88 元 | +6,875 元 | — |
| **合计** | **36.75 万** | **45.52 万** | 1.24 |

**结论**：波动电价下调整机制价值由 15.90 万增至 **23.34 万（高约 47%）**，
而融合价值仅增 7%。调整机制相对重要性由 43% 升至 51%，**超过融合预报**。
边际递减形态也不同：固定电价下加 18 点已零收益，波动电价下仍有 +6,875 元正收益
—— 电价波动**推迟了**调整机制的饱和点。

## 七、模型评价与推广（约 1 页）

### 7.1 优点
1. **统一框架**：四问共享"预测 → 场景 → LP → 滚动执行"结构，逐层增加不确定性维度
2. **报童理论支撑**：用 80% 临界分位解释计划量的经济含义（Q2），并在 Q3 中通过场景树自然推广
3. **严格非前视**：所有预测/融合权重只用历史已实现数据；场景树按"届时新发布"分支
4. **LP 松弛紧性**（Q1）：证明无需二元变量，大幅降低计算量
5. **联合场景**（Q4-2）：保留电价—净负荷相关性，理论正确

### 7.2 局限（诚实列出）
1. 有限经验场景 + 滚动执行，**不保证全年随机控制的全局最优**
2. 电量口径与结算的若干假设（取消退款、按供电时段计价）来自对题面的合理解释，
   **若换解释需重新优化**（已在核验 JSON 给出敏感性）
3. 预测内核参数（sw4/drift5、t7/drift28）继承自前期研发，其选型过程未完全审计
4. 结果均为**同年回测**，不证明跨年份最优
5. Q3 的 18 点更新收益≈0 是本年度数据结论，不能断言其永远无用

### 7.3 推广方向
- 引入外部气象数据（辐照度、云量、温度）提升光伏预报精度
- 场景树深度自适应（当前固定 4 层）
- 电价预测引入更多特征（日内形状聚类、天气耦合）
- 储能寿命成本建模（当前不计折旧）
