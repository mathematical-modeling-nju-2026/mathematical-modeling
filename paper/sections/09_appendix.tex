\textbf{复现步骤}（在仓库根目录执行）：

\begin{verbatim}
python -m pip install -r requirements.txt

# 问题一
python -X utf8 question1/code/run_q1.py
python -X utf8 question1/code/plot_q1.py

# 问题二（推荐方案：有效残差 + 56 天等权）
python -X utf8 question2/code/run_experiment.py \
       --first-residual 7 --only uniform56 --out recommended_only

# 问题三（四次更新主方案）
python -X utf8 question3/code/run_q3.py --mode all --out reproduced

# 问题四
python -X utf8 question4/part2/code/run_q42.py --primary joint_price
python -X utf8 question4/part3/code/run_q3.py --mode all --out out
\end{verbatim}

\textbf{说明}：
\begin{itemize}[itemsep=2pt,topsep=3pt]
  \item 各脚本内部路径均相对于文件位置，从任意工作目录用脚本绝对路径启动均可。
  \item 问题二\textbf{无参数默认运行的是原始残差口径候选}，
        不是最终推荐方案，须按上述命令显式指定 \texttt{--first-residual 7}。
  \item 运行主程序会覆盖同名结果文件；论文使用的现有结果应先备份。
\end{itemize}

\textbf{信息扰动测试的具体做法}（以问题三为例）：
在 2 月 1 日、6 月 21 日、12 月 21 日的四个发布时刻，
\textbf{修改当天及未来的全部实际值与未发布预报}，重建预测、残差、融合权重、场景树与 LP，
检查\textbf{当前的预测结果与控制量是否保持不变}。结果显示决策完全不变，
证明程序未使用任何未来信息。
