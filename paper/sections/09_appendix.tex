\textbf{依赖安装}（若评委环境未安装上述库，请先执行；离线环境可先在有网机器
执行 \texttt{pip download} 再拷贝安装）：

\begin{verbatim}
python -m pip install -r Q4/part3/requirements.txt

# 或直接指定（与本文实测版本一致）
python -m pip install "numpy>=2.5" "scipy>=1.18" "pandas>=3.0" "openpyxl>=3.1"
\end{verbatim}

\textbf{依赖自检}（可选，确认各库可正常导入）：

\begin{verbatim}
python -c "import numpy,scipy,pandas,openpyxl; \
print(numpy.__version__,scipy.__version__,pandas.__version__,openpyxl.__version__)"
\end{verbatim}

\textbf{复现步骤}（先进入支撑材料根目录，再执行下列命令；
已按此顺序\emph{实测通过}，各脚本均写入本问 \texttt{results/} 根目录）：

\begin{verbatim}
python -m pip install -r Q4/part3/requirements.txt

# 问题一
python -X utf8 Q1/q1_code/run_q1.py

# 问题二：三个实验口径 -> 独立核验 -> 发布推荐结果 -> 题目要求表
python -X utf8 Q2/code/run_experiment.py
python -X utf8 Q2/code/run_experiment.py --extended \
       --only uniform28 uniform42 online_extended \
       --out extensions/short_windows
python -X utf8 Q2/code/run_experiment.py --first-residual 7 --initial 8550 \
       --only uniform56 half_life28 online_primary \
       --out sensitivity/valid_residuals
python -X utf8 Q2/code/verify_window.py
python -X utf8 Q2/code/verify_window.py \
       --root Q2/results/extensions/short_windows
python -X utf8 Q2/code/verify_window.py \
       --root Q2/results/sensitivity/valid_residuals
python -X utf8 Q2/code/check_information.py
python -X utf8 Q2/code/report_experiment.py      # 发布推荐结果到 results/ 根
python -X utf8 Q2/code/make_target_tables.py     # 题目要求的表1/表2/表3

# 问题三（四次更新主方案）
python -X utf8 Q3/code/run_q3.py --mode all
python -X utf8 Q3/code/run_q3.py --mode at_0_6_12   # 0/6/12 点对照
python -X utf8 Q3/code/verify_q3.py              # 独立核验

# 问题四-2（依赖问题二已发布的结果作为同口径基准）
python -X utf8 Q4/part2/code/run_q42.py --primary joint_price
python -X utf8 Q4/part2/code/verify_q42.py
python -X utf8 Q4/part2/code/check_information.py
python -X utf8 Q4/part2/code/report_q42.py       # 发布主方案到 results/ 根

# 问题四-3
python -X utf8 Q4/part3/code/run_q3.py --mode all
python -X utf8 Q4/part3/code/run_q3.py --mode at_0_6_12   # 0/6/12 点对照
python -X utf8 Q4/part3/code/verify_q3.py        # 独立核验
\end{verbatim}

\textbf{说明}：
\begin{itemize}[itemsep=2pt,topsep=3pt]
  \item 各脚本内部路径均相对于文件位置，从任意工作目录用脚本绝对路径启动均可。
  \item \textbf{不要给 \texttt{run\_q3.py} / \texttt{run\_q42.py} 传 \texttt{--out}}：
        这两个脚本默认写入本问 \texttt{results/} 根目录，一旦指定 \texttt{--out}
        就会写入子目录，导致后续核验脚本找不到结果。
  \item 问题二的 \texttt{--out} 是\emph{实验分组}用途（\texttt{extensions/}、
        \texttt{sensitivity/}），必须与 \texttt{report\_experiment.py} 配合，
        由后者把推荐方案发布到 \texttt{Q2/results/} 根；只跑第一个命令
        而不跑 \texttt{report\_experiment.py}，后续脚本会找不到
        \texttt{schedule\_detail.csv.gz}。
  \item 问题二\textbf{无参数默认运行的是原始残差口径候选}，
        不是最终推荐方案，推荐方案由 \texttt{sensitivity/valid\_residuals} 与
        \texttt{report\_experiment.py} 共同确定。
  \item 各问的 \texttt{verify\_*.py} / \texttt{check\_information.py} 是
        \textbf{发布前置门槛}：核验不通过时后续 \texttt{report\_*.py} 会拒绝执行。
  \item 运行主程序会覆盖同名结果文件；论文使用的现有结果应先备份。
\end{itemize}

\textbf{信息扰动测试的具体做法}（以问题三为例）：
在 2 月 1 日、6 月 21 日、12 月 21 日的四个发布时刻，
\textbf{修改当天及未来的全部实际值与未发布预报}，重建预测、残差、融合权重、场景树与 LP，
检查\textbf{当前的预测结果与控制量是否保持不变}。结果显示决策完全不变，
证明程序未使用任何未来信息。
