## 使用图片与文字

- PDF 为含嵌入字体的矢量输出，PNG 为320 DPI。图幅宽度统一180 mm，各图按面板数量调整高度。建议正文通栏排版；若正文版心较窄，可按宽度等比缩小，避免将四日面板塞入单栏。
- 字体统一使用系统中的 Microsoft YaHei（不可用时选 Noto Sans CJK SC 或 SimHei），刻度约8 pt、坐标说明8.5 pt、面板标题9.5 pt。背景纯白，使用同一套蓝、橙、灰、紫和绿色。
- 蓝/橙在有正负差值的图中分别表示增加/减少，热力图含以零为中心的色标；在费用构成图中蓝/橙分别对应计划费/紧急费，并用图例明确。灰色表示基线或历史对照，深色表示总量，绿色表示储能状态。不能只根据颜色判断“更优”。
- 每幅图的完整文字见 [图注与正文.md](图注与正文.md)。`insert_figures.tex` 包含可直接选用的图片环境、图注、标签和正文段落；其中路径按新主文件位于 `paper/` 设计。
- `data/` 保留绘图表格；`manifest.json` 记录各图的源文件映射、输入/输出哈希、参数与实际环境。精确结果以表格/原结果文件为准，图内标签按阅读尺度取舍小数位。

## 重绘

从仓库根目录运行：

```powershell
python -B -X utf8 paper/figure_package/build_figures.py
python -B -X utf8 paper/figure_package/verify_package.py
```

脚本也可以通过绝对路径从任意目录运行。基础依赖：`numpy`、`pandas`、`matplotlib`；核验使用 `pymupdf` 和 `Pillow`。复用仓库 `common/plotting/setup_style.py` 与 `export_figure.py`，不需要机器上的技能目录。实际版本见 `manifest.json`。

重绘会更新本图包的图片、数据、Markdown、HTML、LaTeX片段及来源清单；仅读取已保存优化结果，不调用求解器，不修改模型和正式结果。

图文PDF预览需要XeLaTeX和Windows中文字体。在本目录执行：

```powershell
xelatex -interaction=nonstopmode -halt-on-error figure_book.tex
xelatex -interaction=nonstopmode -halt-on-error figure_book.tex
Copy-Item -LiteralPath figure_book.pdf -Destination 图文预览.pdf
```

重绘后须重新编译预览PDF。HTML和Markdown在每次重绘时自动同步；不需要LaTeX即可使用单张图片。

## 取舍与旧材料处理

1. 第一问旧图的光伏消纳/套利拆分使用硬编码金额，且与旧论文存在冲突。本图包采用可由逐段输入和购电决策独立复算的少购减费/增购加费分解，不沿用争议归因，也不修改原模型费用。
2. 第二问采用三种有完整两口径配对的规则，连接的是实测回测点，没有画成置信区间；原11项实验全部附在数据表。该图说明最终规则的选择依据，不将小幅改善包装成全年持续收益。
3. 第三问费用图展示逐级收益，调度图突出相对0点计划的变化。避免两条绝对曲线几乎重合而掩盖改动。
4. 4-2以原Q2按同一实际价格重新结算为基准。没有直接用固定电价Q2费用与波动电价4-2费用相减评判优劣；也没有把当日电价已知对照称为理论最优下界。
5. 4-3跨情形差额是账面分解，不是仅由“波动性”或“预报误差”造成的因果成本。热力图保留全部十分钟值，使用全范围对称色标，没有为突出颜色进行分位截断。储能差包含不同初始状态的历史影响。
6. 共用的预测融合图只在第三问展示；4-3不重复。未再增加一套4-3绝对调度图，也未通过改配色制造虚假差异。

旧 `paper/main.tex`、`main.pdf`、`sections/`、`figs/` 及各问原有图片保留作历史材料，未覆盖或删除。新图包入口已添加到 `paper/README.md`。未顺带修改其他模型或修复无关问题。

## 验证范围

绘图过程检查输入未变、日期/时段唯一配对、统计期与初末状态、费用恒等式、334天或四日完整性、文字未越出画布。核验脚本独立检查来源/输出哈希、图文数量、尺寸、PDF文本及关键派生表。所有图片及图文PDF还需人工视觉检查；本次交付记录见 `核验记录.md`。

这些检查用于确认新图正确表达已有结果，不能替代新的模型复现或证明模型假设、全局最优性与跨年份稳健性。
