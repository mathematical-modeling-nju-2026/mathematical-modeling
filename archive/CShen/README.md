## 一、问题本质：这是一道报童问题

题面关键句："除紧急购电费用外，其他时间段的购电费用均按计划购电量计算。"

⟹ 计划量照付（$c_o = p$），仅缺额加价（$c_u = 4p$）⟹ 报童临界分位

$$F^* = \frac{c_u}{c_o + c_u} = \frac{4}{5} = 0.80$$

**即：每天 0:00 的最优计划净供给应落在当天净负载分布的 80% 分位。**
该结论不依赖分布假设、不依赖电价形状，**只来自"5 倍"这一个数字**。

实测主模型覆盖率中位数 **0.804**，完美吻合。

## 二、最优方案（方案B）：五件套，缺一不可

| 组件 | 内容 | 单步贡献 |
|---|---|---|
| ① **预测器** | `L[sw4/d5] + V[t7/d28]`：同星期几均值 + **漂移校正** | **−20.7 万** |
| ② **计划平衡** | 不等式 `g + d − c ≥ N̂`（保留报童自由空间）| −1.4 万 |
| ③ **时域终端** | 48h 滚动前瞻 + **周期终端**（末段电量 = 起点电量）| −1.0 万 |
| ④ **场景** | 最近 56 天整日联合残差，等权不削减 | — |
| ⑤ **结构** | 两阶段随机规划（计划非前瞻，紧急购电场景补救）| 框架基础 |

### 关键结论

- **漂移校正是最大单步收益（−20.7 万）**：滚动均值有季节滞后 → 系统性偏差 → 本题双向惩罚（弃电浪费 + 5 倍紧急电价）→ 必须校正。MAE 仅降 1%，但日净偏差压到近零。
- **不等式是建模正确性问题**：等式会钉死计划，紧急购电虚高约 3.7 倍。
- **周期终端无参数优于标定 λ**：λE 与周期终端数值等价（1463.3 vs 1463.5），但周期终端更干净。
- **GBDT/场景树等复杂方法无增益**：残差场景已吸收预测误差，简单规则 + 报童分位才是正解。

## 五、被否定的方向（避免重复踩坑）

| 方向 | 结果 | 否定原因 |
|---|---|---|
| 日内实时重优化储能 | 2241.6 万 | 违背题意；且实测缺口 464.65 ≤ 储能上限 833.33，调整空间本为零 |

| 电价加权风险系数 $z\tilde p_t\sigma_t$ | 1797.8 万 | 负载误差是整体性的，非随电价变化 |
