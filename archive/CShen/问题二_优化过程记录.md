## 三、逐步归因

### 阶段 0 → 1：确定性 → 随机规划（−143.6 万，最大单次跃升）

| 项 | 我方基线 | 队友1 |
|---|---|---|
| 预测 | 历史 7 天同时段 q 分位数 | GBDT 分位数回归（84 天窗口）|
| 规划 | 确定性 LP + 分位数裕度 | 24h 随机规划 + 残差场景 + CVaR |
| 决策 | 单日独立 | 逐日滚动 |

**结论**：从"确定性 + 保守裕度"到"随机规划 + 场景"，是**框架级**跃升，收益远超任何调参。

### 阶段 1 → 2：24h → 48h 滚动前瞻（−49.2 万）

**关键洞察**：单日模型是**退化的**——日末储能当日内毫无价值，最优解会把电池一路抽干到 1200 kWh，破坏跨日衔接。

**解法**：0:00 优化未来 48h，只执行前 24h，次日重优化（rolling horizon）。

### 阶段 3 → 5：终端处理与约束形式（合计 −2.4 万）

| 改动 | 结果 | 说明 |
|---|---|---|
| 24h + 线性终端价值 λE（λ=0.4708，1 月标定）| 1463.3 万 | 以"储能边际价值"近似跨日最优 |
| 改"计划等式 + 周期终端" | 1463.5 万 | **与 λ 法几乎等价**（差 0.2 万）|
| 改"不等式 + 周期终端"（单日）| 1461.9 万 | 恢复报童自由度 |
| 改"不等式 + 48h + 周期终端" | 1460.9 万 | 最终结构 |

**两个重要发现**：

1. **λE 与周期终端数值等价**（1463.3 vs 1463.5）——印证"线性终端价值是周期终端的线性近似"。周期终端**无参数**、更干净，优于标定 λ。
2. **约束形式是建模正确性问题**：写成等式 `g+d−c = N̂` 会把计划净供给钉死在点预测上，丧失报童模型"可自由超计划"的空间；改为 `≥` 后，松弛量即"超计划购电量"（含光伏过剩无法消纳的部分）。

### 阶段 6：漂移校正预测器（−20.7 万，**最大单步收益**）

## 四、预测方案对比（核心章节）

### 4.1 三种预测方案

| 方案 | 负载通道 | 光伏通道 | 出处 |
|---|---|---|---|
| **P-A** 移动平均 | 过去 7 天同时段均值 / 同星期几均值 | 近 7–14 天趋势或均值 | 我方基线、队友2 早期 |
| **P-B** GBDT 分位数 | GBDT 分位数回归（时刻/星期/年内日/滞后 1-7-14-28 天等特征，84 天窗口）| 同左 | 队友1 |
| **P-C** 漂移校正 | 最近 **4 次同星期几**均值 + 近 **5** 天误差校正 | 近 **7** 天均值 + 近 **28** 天误差校正 | **最优方案** |

### 4.2 实测对比

| 预测器 | 接入的框架 | 总费用 | 结论 |
|---|---|---|---|
| P-A（q 分位数）| 确定性 LP | 1700.6 万 | 框架不匹配 |
| P-A（同星期几均值）| 48h 随机规划 | 1460.9 万 | 阶段 5 |
| **P-C（漂移校正）** | 48h 随机规划 | **1440.2 万** | ✅ **阶段 6，最优** |
| P-B（GBDT 分位数）| 48h 随机规划 | 1654.2 万 | ❌ 反而更差 |
| P-B（GBDT 分位数）| 24h 随机规划 + CVaR | 1557.0 万 | ❌ 仍不及 P-C |

**关键结论**：

1. **GBDT 不是最优解**：虽然其 MAE 最低（71.8 kWh 级），但在"整日残差场景 + 报童分位"框架下反而更差（1654 万）。原因：**残差场景已吸收了预测误差**，预测只需"足够好"的基线；GBDT 的偏保守中位数点预测会破坏 newsvendor 分位基准。
2. **漂移校正才是关键**：P-C 的 MAE（242 kW 级）**高于** P-B，但总费用低得多。说明本题**"系统性偏差"远比"随机误差"重要**。

### 4.3 为什么漂移校正是关键

**机制**：滚动均值预测存在**季节性滞后**——例如 3 月天气回暖，但"过去 4 周同星期几均值"仍停留在冬季水平，导致预测**系统性偏低**。

**本题成本函数对系统性偏差高度敏感**（双向惩罚）：

| 偏差方向 | 后果 | 边际成本 |
|---|---|---|
| 计划系统性偏高 | 多买电、用不掉 → 弃电 | 计划费浪费 $p_t$ |
| 计划系统性偏低 | 缺口 → 紧急购电 | **5 倍** $p_t$ |

**漂移校正公式**：

$$
\hat N_d = \text{kernel}(d) + \frac{1}{m}\sum_{i=d-m}^{d-1}\Big(N_i - \text{kernel}(i)\Big)
$$

- 负载通道 $m=5$ 天（负载日间变化快）；
- 光伏通道 $m=28$ 天（光伏受季节影响，需更长窗口平滑）。

**效果**：MAE 仅降约 1%，但**日净偏差从数十 kWh 压到接近于零**——后者才是关键。

### 4.4 预测器选型方法（防过拟合）

队友2 用**坐标下降**在 **1 月**上比选：

1. 9 个候选内核（`w1 / sw2 / sw4 / t7 / t14 / bsw / b7 / ew7` 等）× 10 个漂移长度（`0,1,2,3,5,7,10,14,21,28`）；
2. 先固定光伏通道、选负载通道；再固定负载通道、选光伏通道；
3. 评价指标：1–2 日前向 MAE（prequential，逐日滚动评估）；
4. 选定 `L[sw4/d5] + V[t7/d28]`，**2–12 月冻结不再调参**。

> **防过拟合要点**：调参只用 1 月，且 1 月内部也遵循"用当天之前的数据预测当天"，不构成前视。

## 五、被否定的方向（避免重复踩坑）

| 方向 | 结果 | 否定原因 |

| **年末强制储能归零** | — | 题目无此要求，且会浪费储能价值 |

## 六、最终方案（五件套，缺一不可）

| 组件 | 内容 | 单步贡献 |
|---|---|---|
| ① **预测器** | `L[sw4/d5] + V[t7/d28]`（同星期几均值 + 漂移校正）| **−20.7 万** |
| ② **计划平衡** | 不等式 `g + d − c ≥ N̂`（保留报童自由空间）| −1.4 万 |
| ③ **时域终端** | 48h 滚动前瞻 + 周期终端（末段电量 = 起点电量）| −1.0 万 |
| ④ **场景** | 最近 56 天整日联合残差，等权不削减 | — |
| ⑤ **结构** | 两阶段随机规划（计划非前瞻，紧急购电场景补救）| 框架基础 |

**理论支撑**：报童临界分位

$$
F^* = \frac{c_u}{c_o + c_u} = \frac{5p - p}{p + (5p - p)} = \frac{4}{5} = 0.80
$$

实测主模型计划覆盖率中位数 **0.804**，与理论值 0.80 完美吻合。

## 九、经验教训

1. **框架升级 > 参数调优**：确定性 → 随机规划收益 143.6 万，远超任何调参。
2. **"系统性偏差"比"随机误差"更致命**：漂移校正只降 1% MAE，却省 20.7 万——本题对系统性偏高/偏低双向惩罚（弃电浪费 + 5 倍紧急电价）。
3. **终端条件要从经济含义出发**：储能价值只在"明天的高峰电价"里 → 需跨日前瞻或周期终端；且周期终端**无参数**，优于标定 λ。
4. **平衡约束的不等式形式是建模正确性问题**，不是技巧。
5. **不要为"更复杂"而复杂**：GBDT、场景树等复杂方法在本框架下均无增益；简单规则的**逐日滚动 + 整日残差场景 + 报童分位 + 漂移校正**已是本题正解。
