# 历史与未采用方案

原 `C_yang`、`CShen` 和 `M2_E01_v1_滚动随机日前调度` 中未选为最终方案、也未提取为公共依赖的文件保留在这里；不永久删除不确定文件。原始目录名用于追溯，不代表当前主方案。

- `C_yang/`：早期第一、二问实现及旧结果；抽出的公共数据/绘图模块已移到 `common/`。
- `CShen/`：方案A、早期方案C、归因实验、优化过程记录等；早期方案C的数据模块仍供第三问部分历史诊断导入。
- `M2_E01_v1_滚动随机日前调度/`：另一条随机调度路线及论文材料，完整保留。
- `smoke/`、`caches/`、`temporary/`：短期冒烟结果、已有字节码和Excel临时文件，均不作论文主结果。
- `documentation/`：整合前的入口文档副本，供追溯，不作为当前运行指令。

保留不等于承诺历史项目可直接运行：部分原本依赖个人盘符、外部预测器或缺失中间缓存。全仓库扫描发现的引用记录在 `docs/layout_validation.json`。最终四问的活动代码不依赖个人技能目录或这里的主方案；仅第三问探索诊断有已注明的历史模块依赖。
